## Структура локальной базы данных

Все данные пользователя сохраняются в SQLite базу данных (`bookdesk.db`):

- **board_data** - кэш данных досок (книги с фильтрами и сортировкой)
- **book_ratings** - рейтинги книг пользователя
- **book_votes** - количество лайков книг
- **user_votes** - лайки пользователя (массив)
- **book_dates** - даты добавления книг и их статусы
- **book_notes** - заметки пользователя к книгам
- **goal_items** - элементы целей (прочитанные страницы)
- **user_goal** - цели пользователя (количество страниц, тип)
- **user_profile** - профиль пользователя
- **categories** - категории книг (кэш)

## Рекомендации

1. **Через 10 дней можно отключить все операции записи** - все данные уже сохраняются в локальную БД
2. **Операции чтения можно сделать опциональными** - приложение будет работать полностью офлайн после первоначальной синхронизации
3. **Оставить только критически важные API:**

## Проверка перед отключением

Перед полным отключением API рекомендуется:

1. ✅ Убедиться, что все пользователи зашли в приложение хотя бы раз (для синхронизации данных)
2. ✅ Проверить, что все операции работают через локальную БД
3. ✅ Протестировать работу приложения в офлайн режиме
4. ✅ Убедиться, что fallback на сервер работает корректно для новых пользователей
